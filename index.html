What this prototype does—and doesn’t

It demonstrates a deterministic local policy decision and rejection paths. The demo treats a request as admissible only when its sender flag, nonce, block window, allowlisted target, transaction count, and value-plus-fee reserve pass. It does not create a QoreChain EVM authorization window, use an ML-DSA key, enforce on-chain spending rules, estimate actual gas, or send funds. Real implementation must bind the user’s explicit QoreX authorization to a bounded EVM window and a safe target; a target allowlist alone does not cap token amounts or make a generic router safe.
